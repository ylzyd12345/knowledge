配置 步骤

STEP 01

获取阿里百炼 API Key

登录阿里云百炼控制台，创建 API Key。百炼提供 OpenAI 兼容接口，支持 Qwen 全系列模型。

URL # 百炼控制台 https://bailian.console.aliyun.com/ # API 端点 (OpenAI 兼容) Base URL: https://dashscope.aliyuncs.com/compatible-mode/v1
提示：新用户通常有免费额度，可用于测试和开发。
STEP 02

安装 CC Switch

CC Switch 是一个轻量代理工具，用于将 OpenAI 协议的请求转发到阿里百炼的兼容端点。

Terminal # 使用 npm 全局安装 npm install -g @cc-switch/cli # 或使用 npx 直接运行（无需安装） npx @cc-switch/cli
STEP 03

配置 CC Switch 转发规则

创建配置文件，指定阿里百炼作为上游 API。CC Switch 会自动处理协议转换和模型映射。

config.yaml port: 11434 providers: - name: bailian base_url: https://dashscope.aliyuncs.com/compatible-mode/v1 api_key: sk-xxxxxxxxxxxxxxxxxxxxxxxx models: - qwen-max - qwen-plus - qwen-turbo - qwen3-coder-plus
提示：将 api_key 替换为你在百炼控制台获取的真实 Key。建议使用环境变量 BAILIAN_API_KEY 避免明文存储。
STEP 04

启动 CC Switch 代理服务

启动后，CC Switch 会在本地监听指定端口，作为 Codex++ 与百炼 API 之间的桥梁。

Terminal # 启动代理服务 cc-switch --config config.yaml # 默认监听地址 http://localhost:11434
STEP 05

配置 Codex++ 连接代理

在 Codex++ 中设置自定义 Base URL 指向本地 CC Switch 代理，并填入百炼 API Key。

Codex++ Settings # 环境变量方式（推荐） OPENAI_BASE_URL=http://localhost:11434/v1 OPENAI_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxx # 或在 Codex++ 设置界面中填写： API Base URL: http://localhost:11434/v1 API Key: sk-xxxxxxxxxxxxxxxxxxxxxxxx Model: qwen-max / qwen3-coder-plus
注意：API Key 填写的是阿里百炼的 Key，而非 OpenAI 的 Key。Codex++ 通过 CC Switch 代理会将请求正确转发。
STEP 06

验证配置 & 开始使用

发送测试请求验证连通性，确认模型正常响应后即可开始日常使用。

Test # 快速测试 API 连通性 curl http://localhost:11434/v1/chat/completions \ -H "Content-Type: application/json" \ -d '{ "model": "qwen-max", "messages": [{"role": "user", "content": "Hello!"}] }'
成功标志：返回 JSON 响应中包含 choices 字段，且模型正常回复即表示配置完成。
