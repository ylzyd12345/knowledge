# 基本语法

> 变量、数据类型、运算符及控制流程基础。

本文介绍 Java 程序的基本书写规则与流程控制，是阅读任何 Java 代码的前提。面向对象、集合、并发等专题不在本篇展开。

---

## 概念定义

**基本语法**指 Java 源文件中变量声明、数据类型、运算符及控制流程（分支与循环）等语言层面的基础规则。编译器在编译期依据这些规则进行词法、语法分析与类型检查。

### 基本数据类型

| 类型 | 大小 | 说明 |
|------|------|------|
| `byte` | 1 字节 | 整型 |
| `short` | 2 字节 | 短整型 |
| `int` | 4 字节 | 默认整型 |
| `long` | 8 字节 | 长整型，字面量加 `L` |
| `float` | 4 字节 | 单精度浮点，字面量加 `f` |
| `double` | 8 字节 | 默认浮点 |
| `char` | 2 字节 | Unicode 字符 |
| `boolean` | — | `true` / `false` |

引用类型包括类、接口、数组等，变量存储对象引用而非对象本身。

### 变量与常量

- **局部变量**：方法或块内声明，须先赋值后使用。
- **成员变量**：类中定义，有默认初始化。
- **常量**：`final` 修饰，赋值后不可变；类常量常用 `static final`。

## 核心原理

### 1. 标识符与关键字

标识符由字母、数字、`_`、`$` 组成，不能以数字开头。`if`、`class`、`public` 等为保留关键字，不可作标识符。

### 2. 运算符

| 类别 | 运算符 | 说明 |
|------|--------|------|
| 算术 | `+ - * / %` | `%` 为取模 |
| 关系 | `== != > < >= <=` | 返回 boolean |
| 逻辑 | `&& \|\| !` | 短路逻辑 |
| 位运算 | `& \| ^ ~ << >>` | 按位操作 |
| 赋值 | `= += -=` 等 | 复合赋值 |
| 自增自减 | `++ --` | 前缀/后缀语义不同 |

**注意**：`==` 比较基本类型为值相等；比较引用类型为地址是否相同。

### 3. 流程控制

**分支**：

```java
if (condition) { } else if (condition) { } else { }
switch (value) { case 1: break; default: break; }
```

Java 12+ 支持 `switch` 表达式；`String` 自 Java 7 起可用于 `switch`。

**循环**：

```java
for (int i = 0; i < n; i++) { }
for (int item : array) { }  // foreach
while (condition) { }
do { } while (condition);
```

`break` 跳出循环，`continue` 跳过本次迭代。

### 4. 类型转换

- **自动提升**：小范围类型参与运算时自动转为更大范围（如 `int` 与 `long`）。
- **强制转换**：`(type) value`，可能损失精度或溢出。
- **自动装箱/拆箱**：基本类型与包装类转换（详见包装类与自动装箱专题）。

## 实际应用

### 示例一：输入校验与分支

```java
public static String grade(int score) {
    if (score < 0 || score > 100) {
        return "无效分数";
    }
    if (score >= 90) return "A";
    if (score >= 80) return "B";
    if (score >= 60) return "C";
    return "D";
}
```

### 示例二：循环与累加

```java
public static int sumArray(int[] arr) {
    int sum = 0;
    for (int n : arr) {
        sum += n;
    }
    return sum;
}
```

### 示例三：switch 多分支（Java 14+ 表达式）

```java
String dayType = switch (day) {
    case 1, 2, 3, 4, 5 -> "工作日";
    case 6, 7 -> "周末";
    default -> "未知";
};
```

## 源码分析

Java 语言规范对运算符优先级与类型提升有明确定义。`javac` 在编译期完成类型检查，例如：

```java
int a = 1;
byte b = 2;
// byte c = a + b;  // 编译错误：a+b 结果为 int
byte c = (byte) (a + b);  // 需显式强转
```

这体现了 Java 强类型与编译期检查的设计哲学。

## 面试常见题目

**1. Java 有哪些基本数据类型？**

8 种：`byte`、`short`、`int`、`long`、`float`、`double`、`char`、`boolean`。

**2. `==` 与 `equals` 的区别？**

`==` 比较基本类型为值，比较引用为地址。`equals` 是对象方法，默认同 `==`，常按语义重写（如 `String` 比较字符内容）。

**3. `&` 和 `&&` 的区别？**

`&` 为按位与或逻辑与（非短路）；`&&` 为逻辑与且短路——左侧为 false 时不计算右侧。

**4. `break` 和 `continue` 的区别？**

`break` 结束整个循环；`continue` 跳过当前迭代进入下一次。

**5. `switch` 能否用 String？**

Java 7+ 支持；编译器将 `switch` 转为哈希与 `equals` 比较的字节码。

## 思维发散

1. 为何 Java 选择强类型而非脚本语言的弱类型？编译期错误前移、IDE 支持、大型项目可维护性。
2. `foreach` 循环能否修改数组元素？可修改元素值，不可改变数组引用本身；对 `List` 迭代时删除元素需用 `Iterator`。
3. 从基本语法到面向对象：何时用 `static` 方法、何时定义类？见面向对象编程专题。
