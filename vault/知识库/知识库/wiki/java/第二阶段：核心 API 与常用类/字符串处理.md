# 字符串处理

> String、StringBuilder、StringBuffer 的用法与区别。

本文介绍 Java 字符串相关类的使用与选型。字符编码与国际化见其他专题；正则表达式仅作应用提及。

---

## 概念定义

| 类 | 可变性 | 线程安全 | 适用场景 |
|----|--------|----------|----------|
| `String` | 不可变 | 安全 | 常量、键值、少量拼接 |
| `StringBuilder` | 可变 | 非安全 | 单线程大量拼接 |
| `StringBuffer` | 可变 | `synchronized` 安全 | 多线程拼接（少用，有更好方案） |

`String` 内部为 `byte[]`（Java 9+，Compact Strings）或 `char[]`（旧版），一旦创建内容不可变。

---

## 核心原理

### 1. String 不可变

修改操作（`concat`、`replace`）均返回新对象。利于缓存哈希、线程安全、字符串池复用。

### 2. 字符串常量池

字面量 `"hello"` 进入常量池；`intern()` 将堆中字符串尝试放入池中。

```java
String a = "hello";
String b = "hello";
a == b;  // true，同一常量池引用
String c = new String("hello");
a == c;  // false
a.equals(c);  // true
```

### 3. StringBuilder 扩容

内部 `char[]`/`byte[]` 数组，默认容量 16，满则扩容（通常 2 倍 + 2）。

### 4. 常用 API

- `length()`、`charAt()`、`substring()`
- `indexOf()`、`contains()`、`startsWith()`
- `split()`、`join()`（`String` 静态）
- `format()`：`String.format("%s-%d", name, id)`

---

## 实际应用

```java
// 循环拼接必须用 Builder
StringBuilder sb = new StringBuilder();
for (String s : list) {
    sb.append(s).append(",");
}
String result = sb.toString();

// 分割与清洗
String[] parts = "a,b,c".split(",");
String joined = String.join("-", parts);

// 空安全比较
"ok".equals(input);  // 推荐，避免 NPE
```

## 源码分析

`String` 的 `hashCode` 缓存：

```java
private int hash;  // Default to 0
public int hashCode() {
    int h = hash;
    if (h == 0 && value.length > 0) {
        // 计算并缓存
        hash = h;
    }
    return h;
}
```

不可变使哈希码可缓存，提升 `HashMap` 性能。

## 面试常见题目

**1. String 为什么不可变？**

安全（常量池、类加载）、线程安全、哈希缓存、避免副作用。

**2. `+` 拼接与 StringBuilder？**

编译器将简单 `+` 转为 `StringBuilder`；循环内 `+` 每次创建新 Builder，应用显式 Builder。

**3. StringBuilder 和 StringBuffer？**

前者非线程安全、更快；后者方法带 `synchronized`。

**4. `equals` 和 `==` 对 String？**

`==` 比较引用；`equals` 比较内容。

**5. `intern()` 作用？**

将字符串放入常量池，返回池中引用。
