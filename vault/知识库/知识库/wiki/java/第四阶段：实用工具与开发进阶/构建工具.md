# 构建工具

> Maven/Gradle 依赖管理与项目构建。

本文介绍 Maven 与 Gradle 的核心概念与常用命令。CI 流水线见 DevOps 专题。

---

## 概念定义

**构建工具**管理依赖、编译、测试、打包、发布。Java 生态主流：

| 工具 | 特点 |
|------|------|
| Maven | XML（pom.xml）、约定优于配置、生命周期固定 |
| Gradle | DSL（Groovy/Kotlin）、灵活、增量构建快 |

**坐标**：`groupId:artifactId:version` 唯一标识依赖。

---

## 核心原理

### 1. Maven 生命周期

`validate → compile → test → package → verify → install → deploy`

插件绑定阶段：`maven-compiler-plugin`、`surefire`（测试）。

### 2. 依赖传递与冲突

Maven 最短路径优先；冲突用 `<dependencyManagement>` 或 `<exclusions>` 统一版本。

### 3. Gradle 基础

```kotlin
plugins { java }
dependencies {
    implementation("org.springframework.boot:spring-boot-starter-web")
    testImplementation("org.junit.jupiter:junit-jupiter")
}
```

### 4. 多模块

父 POM / settings.gradle 聚合子模块，共享依赖与插件版本（BOM）。

---

## 实际应用

```bash
mvn clean package -DskipTests
mvn dependency:tree
gradle build
./gradlew bootRun
```

Spring Boot 父 POM 管理大量依赖版本，子项目只需声明 artifactId。

---

## 源码分析

Maven 基于 Plexus 容器与插件架构；Reactor 解析多模块构建顺序。Gradle 配置缓存与增量编译减少重复工作。

---

## 面试常见题目

**1. Maven 生命周期？**

见上；`clean` 独立生命周期。

**2. 依赖冲突如何解决？**

`dependency:tree` 分析；exclusion、dependencyManagement、统一 BOM。

**3. Maven 和 Gradle 选型？**

Maven 简单标准；Gradle 灵活、构建快，Android 默认。

**4. scope 有哪些？**

compile、provided、runtime、test、system（少用）。

**5. 私服作用？**

缓存中央仓库、发布内部构件（Nexus、Artifactory）。

---

## 思维发散

1. Maven Wrapper 与 Gradle Wrapper 保证构建版本一致。
2. 可重现构建（Reproducible Builds）与哈希锁定。
3. 构建加速：并行模块、远程构建缓存。
