# 知识库文章评分标准

> 版本：v1.0  
> 配套文档：`output/规则.md`  
> 用途：单篇内部三轮迭代时的打分依据；仅输出综合分最高版本。

---

## 1. 评分维度

满分 10 分，加权计算综合分。

| 维度 | 权重 | 考察内容 |
|------|------|----------|
| **结构完整性** | 15% | 八大板块齐全、标题层级正确、frontmatter 完整 |
| **大纲与摘要匹配** | 15% | 覆盖 `目录.md` bullet 要点；summary / blockquote / Index 一致 |
| **深度适配性** | 20% | 篇幅与细节符合 `type`（地图/机制/工具/框架） |
| **边界清晰度** | 15% | 不抢专题篇幅；有「不写/不展开」声明；跨篇不重复堆砌 |
| **可维护性** | 10% | 无死链；`related` 与文末列表一致；便于后续批量加链接 |
| **面试实用性** | 10% | 题量合规、难度匹配类型、答案简要可用 |
| **百科感与可读性** | 10% | 表格/流程图适度、术语准确、无废话堆砌 |
| **批量可复制性** | 5% | 模板统一、示例代码规范、同类文章可照此生成 |

---

## 2. 各维度评分细则

### 2.1 结构完整性（15%）

| 分数 | 标准 |
|------|------|
| 9～10 | frontmatter 四字段齐全；8 个板块完整；`#` 与 `##` 层级无误 |
| 7～8 | 板块齐全但个别小节过薄（仅 1 句） |
| 5～6 | 缺少 1 个板块或 frontmatter 缺字段 |
| &lt;5 | 结构混乱、板块顺序错误或大量缺失 |

**必检清单：**

- [ ] `phase`、`type`、`summary`、`related`
- [ ] 文首 blockquote 与 `summary` 一致
- [ ] 概念定义、核心原理、实际应用、源码分析、面试常见题目、思维发散、相关概念（待扩展）

### 2.2 大纲与摘要匹配（15%）

| 分数 | 标准 |
|------|------|
| 9～10 | index 表摘要全覆盖；大纲 bullet 要点无遗漏 |
| 7～8 | 摘要对齐，bullet 有 1 项略薄 |
| 5～6 | 摘要一致但 bullet 漏 2+ 项，或多了大量超纲内容 |
| &lt;5 | 摘要与 Index 不一致；明显偏离章节主题 |

### 2.3 深度适配性（20%）

| 分数 | 标准 |
|------|------|
| 9～10 | 字数落在类型区间内；板块权重与类型表一致 |
| 7～8 | 略超或略欠 20%，或某一板块权重轻微失衡 |
| 5～6 | 地图型写成机制型深度，或机制型过于浅显 |
| &lt;5 | 完全未按类型区分 |

**类型速查：**

- 地图型：全景 &lt; 机制细节；源码 ≤1 段简短片段
- 机制型：原理 + 源码为核心；面试 6～10 题
- 工具型：示例与配置为主；源码可省略
- 框架型：架构 + 使用；入口类源码即可

### 2.4 边界清晰度（15%）

| 分数 | 标准 |
|------|------|
| 9～10 | 文首定位明确；超纲内容已剔除；与相邻专题无大块重复 |
| 7～8 | 有 1～2 处可挪到专题的段落 |
| 5～6 | 多处专题级内容（如概述里写 GC 算法细节） |
| &lt;5 | 主题模糊，像多篇专题的拼接 |

### 2.5 可维护性（10%）

| 分数 | 标准 |
|------|------|
| 9～10 | 无 `[[链接]]`；`related` 与文末列表一致；概念名与大纲文件名可对应 |
| 7～8 | 偶发正文 wiki 链接或 related 漏项 |
| 5～6 | 大量未解析链接或 related 与文末不一致 |
| &lt;5 | 链接策略混乱，后续难以批量维护 |

### 2.6 面试实用性（10%）

| 分数 | 标准 |
|------|------|
| 9～10 | 题量在类型范围内；难度匹配；答案 3～5 句可背诵 |
| 7～8 | 题量或难度略偏，或 1～2 题无答案 |
| 5～6 | 只列题目；或进阶题大量超出本文 |
| &lt;5 | 无面试板块或与主题无关 |

### 2.7 百科感与可读性（10%）

| 分数 | 标准 |
|------|------|
| 9～10 | 定义准确；表格/流程图帮助理解；段落长度适中 |
| 7～8 | 可读但略密或略水 |
| 5～6 | 大段复制粘贴感；术语错误 |
| &lt;5 | 难以阅读或存在明显技术错误 |

### 2.8 批量可复制性（5%）

| 分数 | 标准 |
|------|------|
| 9～10 | 完全符合 `规则.md` 模板；可作为同类标杆 |
| 7～8 | 小格式差异（如多一个分隔线） |
| 5～6 | 结构自创，与其他篇不易统一 |
| &lt;5 | 无法作为批量模板 |

## 3. 综合分计算

```
综合分 = Σ (维度得分 × 权重)
```

示例（Java概述 终版）：

| 维度 | 得分 | 权重 | 加权 |
|------|------|------|------|
| 结构完整性 | 9 | 0.15 | 1.35 |
| 大纲与摘要匹配 | 9 | 0.15 | 1.35 |
| 深度适配性 | 9 | 0.20 | 1.80 |
| 边界清晰度 | 9 | 0.15 | 1.35 |
| 可维护性 | 9 | 0.10 | 0.90 |
| 面试实用性 | 8 | 0.10 | 0.80 |
| 百科感与可读性 | 8 | 0.10 | 0.80 |
| 批量可复制性 | 9 | 0.05 | 0.45 |
| **合计** | | | **8.85 ≈ 8.7** |

## 4. 三轮迭代与放行门槛

### 4.1 迭代记录格式

每篇内部迭代时记录（可不写入仓库，批量时可记入 `output/生成日志.md`）：

```markdown
## 文章名

| 轮次 | 调整摘要 | 综合分 |
|------|----------|--------|
| 第 1 轮 | 搭骨架 | 7.5 |
| 第 2 轮 | 收边界、补契约 | 8.3 |
| 第 3 轮 | 打磨面试与示例 | 8.7 |

→ 输出：第 3 轮
```

### 4.2 单篇放行门槛

| 条件 | 要求 |
|------|------|
| 综合分 | ≥ **8.0** |
| 任一维度 | 不得低于 **6.0** |
| 深度适配性 | 不得低于 **7.0**（核心维度） |
| 边界清晰度 | 不得低于 **7.0**（核心维度） |

未达门槛：继续迭代（最多 5 轮），仍不达标则标注「待人工修订」并不纳入批量默认同标。

### 4.3 标杆样例

| 文章 | 类型 | 综合分 | 用途 |
|------|------|--------|------|
| Java概述 | 地图型 | 8.7 | 地图型结构与边界标杆 |

批量生成时：同类型文章结构对齐标杆，综合分目标 **≥ 8.0**，机制型难点篇目标 **≥ 8.5**。

## 5. 常见问题与扣分

| 问题 | 主要扣分维度 | 建议 |
|------|--------------|------|
| 概述篇写 GC/AQS 细节 | 深度适配、边界 | 删细节，改「见 ×× 专题」 |
| 全文 `[[链接]]` | 可维护性 | 改为纯文本 + related |
| summary 与 Index 不一致 | 大纲匹配 | 以 `目录.md` index 表为准 |
| 面试题无答案 | 面试实用性 | 每题补 3～5 句 |
| 机制型无源码 | 深度适配 | 补 JDK 片段或典型实现思路 |
| 工具型大段原理 | 深度适配 | 移到原理节压缩，加重示例 |
| 虚构源码 | 百科感 | 删除或改为伪代码并标注 |
| 代码无法编译 | 百科感、可复制性 | 修正 import 与语法 |

---

## 6. 批量质量抽检

每完成一个阶段（6 个阶段），抽检 1 篇并与同类型标杆对比：

- [ ] frontmatter 格式一致
- [ ] 板块标题用词一致（如统一用「面试常见题目」）
- [ ] 相关概念（待扩展）格式一致
- [ ] 该阶段各篇 `type` 与规则表一致

阶段综合均分低于 8.0 时，回溯该阶段全文按规则修订。
